What the code now does

The main pieces of the retrieval setup, in plain language.

📂

Read the documents

Finds text files in the data folder and reports a clear error if the folder or files are missing.

✂️

Split into chunks

Breaks long documents into pieces of up to 500 characters, with a small overlap between pieces.

🔎

Find useful text

Turns chunks into vectors and uses FAISS to retrieve the five closest matches for a question.
